# AI for Business · workshop pages

Static pages for Oguz Sarkut's AI for Business workshops.

- `ai-workshop.html` — landing page for the 7-workshop certificate program (also served at `/`)
- `01-meet-your-ai-coworker.html` — Workshop 01 · Meet Your AI Coworker

Add each new workshop as another file in this folder (e.g. `02-ai-market-analyst.html`) and link it from the landing page.
Deployed on Vercel as a static site; no build step.
